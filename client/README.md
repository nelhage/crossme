# CrossMe client

The CrossMe web client: React + TypeScript, built with [Vite][vite]. It talks
to the Go server over [Connect][connect], which the server speaks natively --
there is no proxy in between.

[vite]: https://vite.dev/
[connect]: https://connectrpc.com/

## Scripts

| Command             | What it does                                                          |
| ------------------- | --------------------------------------------------------------------- |
| `npm run dev`       | Dev server on http://localhost:3000, proxying `/api` to the Go server |
| `npm run build`     | Type-check, then build a production bundle into `dist/`               |
| `npm run preview`   | Serve the contents of `dist/` locally                                 |
| `npm test`          | Run the [Vitest][vitest] suite once (`npm run test:watch` to watch)   |
| `npm run typecheck` | `tsc --noEmit`                                                        |
| `npm run lint`      | ESLint                                                                |
| `npm run format`    | Rewrite files with Prettier (`format:check` to only check)            |

[vitest]: https://vitest.dev/

`../scripts/start-servers` brings up the dev server and the Go server together
in a tmux session.

## Generated protobuf code

`src/pb/` holds the [protobuf-es][protobuf-es] output: message types plus the
`CrossMe` service descriptor, which `@connectrpc/connect` turns into a client
(see `src/rpc.ts` and `src/App.tsx`). It is generated by `../scripts/gen-proto`
and checked in; don't edit it by hand.

[protobuf-es]: https://github.com/bufbuild/protobuf-es
